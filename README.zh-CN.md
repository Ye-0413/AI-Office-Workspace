# AI Work Space

**Observe your agent team collaboration in your spare display**

在闲置屏幕上，观察你的 Agent 团队协作。

把 **Codex、Claude Code、Cursor、OpenCode** 等工具中的真实 AI 会话，汇聚到一间温暖的 macOS 桌面工作室。谁在写代码、谁在等待、谁带着小分身一起忙碌，都有自己的位置与动作。

折纸翻页，墨滴敲键，苔盒搭起小模块，毛线绕出新想法，琥珀里亮着一粒暖光。抬眼看看副屏，就能看见工作，也看见陪伴。

**5 位原创伙伴 · 550 套材质动作 · 28 种工具接入 · 6 间日常＋27 间节日房间**

## 五位伙伴，五种性格

纸、墨、苔藓、毛线与暖光，各有自己的轮廓和动作语言。下面是五位伙伴的**角色与动作设计设定**；文案、编程等方向是它们的性格主题。每只都支持全部 11 类活动，实际任务仍由你使用的 AI 工具决定；当前可播放的动作可在应用图鉴中查看。

### 01 · 纸团 FOLIO — 文案与资料整理

**一页也认真。** 奶油白的折纸小兽，身体像一封还没完全折好的信。两个不对称的纸角是耳朵，四条短短的折纸腿撑住身体，脸藏在层层折痕之间。

它的动作语言是**折叠、翻页、压平**：写作时轻轻展开身体，思考时两只耳角交替折起；完成后的标志性画面，是从身体里抽出一张整齐的小纸条。认真、敏感，还有一点可爱的完美主义，像那个总会替你再检查一遍段落的小伙伴。

### 02 · 墨豆 INK — 编程与排错

**安静，行动快。** 深蓝近黑的扁圆墨滴，低低趴着，四只软脚贴近地面，一道细亮的眼缝藏在轮廓里。它像一颗会流动的小石子，沉默，却很有主意。

它用**流动、伸缩、聚散**表达工作：前脚快速敲键，遇到难题时缩成一小滩，再慢慢鼓起来。小分身从身体里“滴”出去，归返时重新融入主身。安静、倔强，遇到 bug 会停下来盯住那个故障点。

### 03 · 苔盒 MOSS — 长任务与后台维护

**慢慢来，也稳稳地向前。** 矮方形的陶土小兽，四条粗短腿站得很稳，眼睛嵌在陶土凹槽里。背上覆盖着不规则的苔藓与叶片，像一只背着小花园的生物。

它用**叶片、短根、托举**完成动作：稳稳走到工位，托起书页，压实模块；设定中，背上的叶片会舒展，等待时偶尔探出一片新芽。可靠、不着急，很适合长久陪伴。叶片的生长表达性格，实际任务进度仍以工具信息为准。

### 04 · 线团 THREAD — 设计与创意探索

**把想法绕成形。** 珊瑚橙的毛线小兽，身体偏梨形，一只耳朵是线圈，另一只是松散的线头。四肢长短略有差异，保留着亲手编织般的不规整与弹性。

它的动作语言是**拉线、绕形、编织、解结**：思考时把线头绕成不同轮廓，灵感来了，就收成一个漂亮的小结。角色故事里，它偶尔会把自己缠住，等理清思路，再若无其事地解开。活泼、有手作感，连试错都带一点小幽默；真实异常状态会保留线结，等待实际修复证据。

### 05 · 灯籽 GLOW — 协调与提醒

**需要你时，轻轻亮一下。** 半透明的琥珀色种子，上窄下宽，底部有四个小支点，内部悬着一粒暖光。它的表情藏在透光的身体和光点的位置里，轮廓安静而柔和。

它用**内光移动、光点排列、透光**表达状态：协调时光点有节奏地移动，提醒时克制地亮一下，休息时暖光沉到身体底部。温和、精确，适合作为主助手的性格原型，让等待回应也能保持从容。

**一个家族，一眼认出。** 主 Agent 随机获得一种角色；前五个家族使用五种不同的原色造型，更多家族复用造型并获得配色变体。同一场景内，主 Agent 的“造型＋配色”各不相同。分身继承真实根家族的外观，体型更小；在场家族不会因为新伙伴加入或离开而换造型。

五位角色来自用户提供的概念与参考，使用 AI 辅助生成姿态图，再由项目实现渲染、动作编排与状态连接。[查看中英双语原创声明](ORIGINALITY.md)。

## 550 套动作，让忙碌有细节

**5 位伙伴 × 11 类真实活动 × 每类 10 套动作。** 各自使用符合材质的道具、接触顺序和运动路径：纸张折叠与送入，根须敲打叶片键盘，毛线穿过小机构，暖光沿透明轨道运行。

阅读 · 搜索 · 思考规划 · 编程 · 设计 · 测试 · 构建 · 执行 · 等待工具 · 等待用户 · 异常

编程保持持续输入，构建组装结构，执行表现已启动的运行回路。等待时工具停下来；异常保留卡纸、断路、断根或线结，不假装已经修好。单次工具成功只有轻微、去重的回应；整轮完成需要真实完成证据。

打开 **房间偏好 → 工坊伙伴 → 动作图鉴**，可逐一选择角色、活动与动作，播放或暂停查看。[浏览公开动画预览](docs/animations/README.md)。

## 工作看得见，陪伴也有细节

- **多个工具，同一间工作室。** 跨项目、跨工具的独立会话各有身份；同一工具同时运行多个 Agent，也能分别观察。工作、等待、异常与完成来自真实事件。
- **主身与小分身，一眼看清。** 分身从实际父级身上凝聚，走向工位，结束后走回父级；同族外观、名牌与关系树保留真实的多层协作关系。
- **找到正在忙、正在等的那一位。** 用 **⌘K** 按昵称、任务、工具、项目或 ID 搜索，筛选“仅需留意”，查看活动详情与父级。支持键盘选择和房间内定位。
- **看见投入，也看见等待。** 本地使用记录保留活动时间线、工具调用和观测到的工作／等待时长，支持日期、工具与主／分身筛选及活动 CSV 导出。**今日 Token／本周用量**汇总七种工具的本地记录。[查看监测范围](office/docs/monitoring.md)。
- **需要你时，接住那个问题。** 在工作室查看待回应状态；受支持版本的 OpenCode 与 MiMo Code 可由你手动选择或填写原生问题答案。其它工具回原工具处理，工具审批始终由原工具负责。[问答支持范围](office/docs/monitoring.md#manual-native-questions)。
- **身体和名字，调到你看得清。** 手动选择 **65%–135%** 的固定大小，人数变化不会缩小角色或名牌。移动时可以相互穿行，最终工作位置按完整身体与名牌分开安排。
- **每天走进不同的房间。** 六间日常房间、27 间节日房间各有建筑与布局；香港日历与昼夜灯光让空间随时间变化，也可以固定喜欢的房间。界面支持 **中文／English** 切换。[逛逛房间](docs/rooms/README.md)。
- **适合长久开着的陪伴。** 减少动作、节能模式与隐藏窗口暂停，让画面安静下来。家具到站回应、12 种双人互动和可关闭的闲时装饰访客，为工作间隙添一点生活感。

## 支持哪些 AI 工具？

连接目录提供 **28 种工具的活动接入适配**，包括常用的 **Codex CLI、Claude Code、Cursor Agent、Copilot CLI、Gemini CLI、OpenCode、OpenClaw、Hermes Agent**。通过本机 hooks、插件、扩展或适配的会话日志接收活动。

<details>
<summary><strong>查看全部 28 种工具与接入方式</strong></summary>

- **Hooks／日志入口（21）**：Claude Code、Codex CLI、Copilot CLI、Gemini CLI、Antigravity CLI、Cursor Agent、CodeBuddy、Kiro CLI、KiroCrew、Kimi Code、Qwen Code、ZCode、CodeWhale、Qoder、Reasonix、QoderWork、QwenWork、WorkBuddy、TraeCode、Grok Build、MiniMax Code。Codex 同时提供本地会话日志观察。
- **插件事件入口（5）**：OpenCode、MiMo Code、OpenClaw、Hermes Agent、DeepSeek Harness（experimental／实验性）。
- **扩展入口（2）**：Pi、OMP。

</details>

**本地 Token 统计覆盖 7 种工具**：Codex、Claude Code、Gemini CLI、Pi、OMP、Kimi Code、OpenCode。按香港日期汇总今日与本周用量，可读取支持的历史记录；Token 统计与实时角色活动分别记录，不把旧用量当成正在工作。

**原生问题手动回答**支持 OpenCode **1.x（1.18.31 起）**与 MiMo Code **0.1.x（0.1.15 起）**。单选、多选或自填答案均由你明确提交；其它工具与不支持的版本在原客户端处理。

各工具的事件能力取决于宿主版本与接入方式。28 种适配已做配置与事件回归，Codex 已验证真实多 Agent 日志到角色显示，其它客户端仍需实际会话验收。[连接兼容说明](office/docs/upstream-compatibility.md) · [用量覆盖与数据来源](office/docs/monitoring.md#actual-coverage)。

## 本地观察，连接由你决定

工作室读取已适配的本机会话日志，以及你选择接入的 hooks／插件事件。无需云端账号、AI API Key 或遥测服务；设置与观察历史保存在应用的本机数据目录。[存储内容与边界](office/README.md#local-data-and-credits)有详细说明。

打开 **连接 AI 工具 → 一键初始化**，应用会检测已有工具，安装或更新本应用的观察配置，并逐项显示结果；失败项可单独重试。配置只在你明确点击后写入，保留原有设置和其它 hooks。连接完成后，在原工具中产生一次新活动，就能等待自己的伙伴入场。

## 从源码运行

主应用在 **`office/`**。根目录的 package 命令属于保留的上游参考项目。开发需要 macOS、Node.js 24+；构建原生辅助程序需要 Xcode Command Line Tools。

```sh
git clone https://github.com/Ye-0413/AI-Office-Workspace.git
cd AI-Office-Workspace
npm --prefix office ci
npm --prefix office test
npm --prefix office start
```

```sh
# 原生渲染冒烟检查
npm --prefix office run verify:renderer
# 生成本地 .app、DMG 与 ZIP
npm --prefix office run build:mac
```

构建产物位于 `dist-mini-office/`，应用名为 **AI Work Space.app**。五只工坊伙伴已经包含在公开源码中，不需要还原上游角色素材。只有需要旧素材兼容、且拥有使用权限时，才按[应用说明](office/README.md#公开源码版准备)中的可选流程从本地导入。
