# 节令场景与机关动画

山海工坊有 43 幅完整节令／文化／季节灵感室内画面，港湾茶舍和星台观测室保留各自独立背景与节令布景。以下图鉴播放产品当前的原创道具代码，不使用受限 Agent 外观，也不代表真实 AI 任务。

![43 套机关动画](overview.gif)

每套标准机关有 41 个连续姿态采样，持续约一秒；装饰环境还会响应机关，双 Agent 互动持续 2.8–3.2 秒。减少动作、节能或隐藏窗口会结束运动并保留可理解的状态。

## 场景与玩法

- **春日新芽 / Spring shoots**：浇一滴春水。让一株小芽舒展叶片。
- **夏日清风 / Summer breeze**：展开竹扇。竹骨展开，借一阵清凉。
- **秋日拾叶 / Autumn leaf album**：收下一片秋叶。一片枫叶落进小小叶笺。
- **冬日雪瓶 / Winter snow globe**：轻摇雪景瓶。雪花在玻璃里慢慢安静下来。
- **万圣南瓜夜 / Halloween lantern**：点亮南瓜灯。掀开小盖，点亮一个友善的笑脸。
- **圣诞暖灯 / Christmas lights**：打开树下礼盒。礼盒打开，树上的木灯次第亮起。
- **清明纸鸢 / Qingming kite**：放起一只纸鸢。新绿与纸鸢，安静记起想念的人。
- **新年心愿 / New Year wishes**：挂一枚新年愿签。小小愿签挂好，金色纸花散开。
- **新春灯结 / Lunar New Year lantern**：展开新春灯笼。红灯舒展，金结轻轻晃动。
- **中秋望月 / Mid-Autumn moon**：拨开云边望月。云边让开，月兔和圆月相逢。
- **花见樱枝 / Hanami blossom branch**：轻触一枝春樱。三四月的赏花灵感；不是任何地方的花期预报。
- **仲夏花环 / Midsummer wreath**：织起仲夏彩带。花环下，两条彩带交织成新的图案。
- **亡灵节花忆 / Día de Muertos remembrance**：展开万寿菊剪纸。万寿菊、剪纸和暖烛，温柔纪念所爱的人。
- **龙舟击楫 / Dragon boat rhythm**：划一桨龙舟。跟着小鼓点，双桨入水再收回。
- **七夕星桥 / Tanabata star bridge**：搭起一段星桥。把两岸的星点接成一座纸桥。
- **元宵灯谜 / Lantern riddle**：展开一张灯谜。展开谜笺，再翻开一枚小小谜底。
- **排灯小径 / Diwali lamp path**：点一盏陶灯。陶灯依次亮起，照出一条小路。
- **洒红调色盘 / Holi pigment palette**：调一勺彩粉。把不同颜色的小勺轻轻拌进调色碗。
- **彩蛋花纹坊 / Easter egg patterns**：配好半枚彩蛋。让两半彩蛋的条纹和圆点对齐。
- **心笺邮匣 / Valentine paper letter**：折好一封心笺。折起纸笺、合上信封，再盖一枚纸心。
- **三叶草结环 / Shamrock wreath**：展开一株三叶草。三片小叶逐一舒展，绕出一圈青绿细结。
- **秋收分拣台 / Harvest sorting table**：收好一份秋实。把玉米、南瓜和苹果放进不同的小筐。
- **嘉年华羽面 / Carnival feather mask**：展开羽毛面具。面具两侧的纸羽依次舒展。
- **椒盐结工坊 / Pretzel knot workshop**：编一个椒盐结。面绳交叉、翻回，再撒几粒小盐。
- **水灯莲台 / Loy Krathong lotus light**：展开莲瓣水灯。莲瓣展开，烛光沿一圈水纹漂移。
- **泼水涟漪 / Songkran water ripples**：轻倒一勺清水。小水勺倾斜，一串水滴落进浅盆。
- **郁金香苗圃 / Tulip miniature garden**：唤醒一朵郁金香。依次舒展三株不同形状的花苞。
- **薰衣草香笺 / Lavender paper sachet**：包一枚薰衣草香笺。收拢花枝、折好纸角，再系一枚细结。
- **向日葵追光 / Sunflower light study**：转动一束日光。小太阳换个位置，花盘轻轻追随。
- **雨滴木琴 / Raindrop xylophone**：敲响一滴小雨。让一颗雨滴依次触碰长短不同的琴片。
- **雪球小工地 / Snowball workshop**：滚好一枚雪球。从雪地滚来雪球，叠好雪人的围巾。
- **极光织带 / Aurora ribbon loom**：织一条极光带。拨动三条薄薄的光带，织出不同曲线。
- **流星轨道台 / Meteor orbit table**：推一颗轨道流星。沿椭圆轨道推进小流星，留下短短星尾。
- **日影刻度盘 / Solstice shadow dial**：拨动一格日影。手动日影示意，观察影子的长短方向。
- **漂流瓶书桌 / Ocean bottle desk**：展开瓶中的纸卷。拔开软木塞，让小纸卷舒展一张海图。
- **风竹听雨 / Bamboo breeze chimes**：拨动一管风竹。三根竹管错落摆动，纸带接住一阵风。
- **萤火小径 / Firefly path**：点一段萤火路。让萤火虫依次停在叶桥和苔石旁。
- **纸帆折叠台 / Paper sailboat table**：折出一片纸帆。把方纸折成船身，再展开三角小帆。
- **齿轮八音匣 / Clockwork music box**：摇一圈小音匣。掀开匣盖，摇动齿轮，让小木槌轮流抬起。
- **书页藏签 / Book and bookmark**：翻到一枚藏书签。翻过几页小书，留下一枚叶形书签。
- **骑士跳格 / Knight move puzzle**：走一步骑士棋。骑士按日字跳格，棋盘亮出下一站。
- **晨光棱镜 / Dawn prism**：转动晨光棱镜。转动三角棱镜，让一束晨光分成彩色光线。
- **灯火小夜摊 / Lantern night stall**：挂上一盏小摊灯。卷起帘子，再把纸灯挂到小木架上。

## 日期与天气

自动模式使用香港日期和四季月份。农历新春为正月初一至初三，中秋为八月十四至十六；这是房间的装饰窗口。清明使用香港天文台已核实的 2026–2035 日期，范围外可手动选择。圣诞装饰为 12 月 24–26 日，公历新年为 1 月 1–3 日；万圣节为 10 月 31 日，亡灵节为 11 月 1–2 日。仲夏使用瑞典六月 19–25 日之间的星期五与随后星期六。其它文化及季节灵感手动预览，不臆测变化中的节日日期、实际花期或天气。

日期核对：[香港天文台历表](https://www.hko.gov.hk/en/gts/time/conversion.htm)、[香港政府 2026 假期](https://www.info.gov.hk/gia/general/202505/16/P2025051300353p.htm)、[Skansen 仲夏传统](https://skansen.se/se-och-gora/hogtider-traditioner/midsommar/)、[UNESCO 亡灵节文化说明](https://ich.unesco.org/en/RL/dia-de-muertos-the-indigenous-festivity-dedicated-to-the-dead-00054)。

雨、雪、关闭或随主题天气只影响窗外装饰。手动场景与天气不会更改真正的香港时钟、日期、星期或 Agent 状态。

## 生成图鉴

通过 Electron 运行 `office/scripts/render-scene-atlas.cjs`，它调用真实场景模块，输出 41 帧与清单；再以 30 fps 转为 GIF。图集只展示原创物件。基础室内背景的提示位于 `office/assets/scenes/generation.json`；43 幅完整主题画面的最终提示、修订记录、源图与交付图 SHA-256 位于 `office/assets/scenes/themes/generation.json`。通过 `office/scripts/render-scene-rooms.cjs` 可重新导出完整工坊总览。
