## Recording and editing / 录制与后期

- **Source:** the installed v0.24.0 application, captured directly with macOS ScreenCaptureKit at a native window size of **1236 × 690**, at 30 frames per second. Final landscape videos use a **1920 × 1080** editorial canvas; the vertical version uses **1080 × 1920**. These are output canvas dimensions, not native 1080p captures.
- **Real interactions:** studio scenes, parent–helper families, companion search, preferences, sizing and language changes were recorded from the application. The films do not create AI sessions for the recording.
- **Demonstrations:** selected character and activity close-ups come from the application's Motion gallery and are explicitly labeled as demonstrations. Gallery playback does not claim that a real AI session performed that activity.
- **Branding:** the captured v0.24.0 application predates the AI Work Space rename. The films' editorial titles and end cards use the current brand; the recorded interface has not been redrawn as a different application.
- **Privacy:** framing and masking omit private usage information. Public previews are derived from the edited films. Raw window captures, private quality-assurance images and local capture metadata are not included in these public assets.
- **Sound:** the score is synthesized by [the project music script](../../office/scripts/promo/synthesize-workshop-music.py), without downloaded music or external audio samples. No microphone or system audio was recorded.

- **录制源：** 已安装的 v0.24.0 应用，通过 macOS ScreenCaptureKit 直接录制，原生窗口为 **1236 × 690、30 fps**。横版采用 **1920 × 1080** 后期画布，竖版为 **1080 × 1920**；这不表示源录屏具有原生 1080p 分辨率。
- **真实交互：** 房间、主 Agent 与分身、伙伴搜索、偏好设置、大小调整及语言切换均来自应用实际操作，没有为了拍摄而创建 AI 会话。
- **演示范围：** 角色与活动特写来自应用动作图鉴，并在片中明确标注为演示；播放图鉴不代表真实会话正在进行该活动。
- **品牌更新：** 录制时的 v0.24.0 应用早于 AI Work Space 更名。后期标题与片尾使用新品牌，保留录下的实际界面。
- **隐私处理：** 通过取景与遮罩排除私人用量信息；公开预览来自后期成片。原始录屏、私有检查图与本机录制元数据不包含在公开素材中。
- **声音：** 配乐由[项目内的合成脚本](../../office/scripts/promo/synthesize-workshop-music.py)生成，没有使用下载音乐或外部音频采样；录制未采集麦克风或系统声音。

See the [reproduction guide](../../office/scripts/promo/README.md) for capture and rendering commands. / 录制与重新剪辑方法见[制作说明](../../office/scripts/promo/README.md)。
