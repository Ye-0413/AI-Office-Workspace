## What's inside

- **Five different materials:** Folio's folded cream paper, Ink's fluid navy silhouette, Moss's terracotta and roots, Thread's coral yarn, and Glow's translucent amber and inner light. User-supplied concepts were developed with AI-assisted sprite generation and project-authored rendering and motion.
- **550 performances:** ten variations for each of eleven activities on every character. Coding inputs, building assemblies and running mechanisms have distinct visual meanings. Waiting stops work; errors retain their visible fault. Explore the full collection in **Room preferences → Workshop companions → Motion gallery**.
- **Families you can follow:** the first five main families use distinct base designs; further families receive color variants. Helpers inherit the real root's appearance at a smaller size, split at the actual parent and return there. Ink uses a material-specific droplet split and merge.
- **A size you control:** larger base bodies and 29px base nicknames; a fixed manual 65%–135% scale. Counts never trigger automatic shrinking. Moving bodies may cross; final stations keep complete body and label envelopes separate. Bodies awaiting a safe admission remain represented in the roster.
- **Continuous, quieter motion:** unchanged metadata preserves DOM and animation owners. Hidden windows freeze original clocks; reduced motion and low power keep static information. Resource failure uses a local neutral fallback and can recover without changing session identity.
- **A useful local studio:** bilingual English/Chinese UI, companion search with ⌘K, observed activity history, Daily Token and Weekly usage. Six everyday and 27 holiday room designs support a Hong Kong daily schedule. Existing furniture responses, twelve pair interactions and optional decorative visitors remain available.

## Install

**Verified target: macOS 13 or later, Apple Silicon / arm64.** Download the arm64 DMG or ZIP from the [Release page](https://github.com/Ye-0413/AI-Office-Workspace/releases/tag/v0.24.0). Drag **AI Mini Office.app** into Applications, open it, then connect the tools you use and create a fresh event in their original interface. Electron and Node are bundled; a development server is not needed.

Current packages use **local ad-hoc signing and are not Apple-notarized**. macOS may warn that the developer is unidentified. Check the release source and SHA-256 file before deciding to open the app; no system-wide security disabling is required. Windows, Linux and Intel macOS packages are not claimed as verified by this release.

For source builds, use the commands under [Run from source](../../README.md#run-from-source). Root package scripts belong to the retained upstream reference project; the app commands use `npm --prefix office`.

## Evidence and limits

The 550-recipe native audit checks rendered samples across all five characters and eleven activities. An isolated 100-controller fixture checks unchanged metadata, retained animation objects, hidden clock freezing and teardown cleanup. Local timings are diagnostics, not a frame-rate guarantee.

The fixed-size native fixture exercises actual 2→4→2 arrivals, a helper's relative size, manually selected 110%→100% sizing and real simultaneous routes that cross before settling without overlap. It does not claim unlimited capacity in a fixed room. Furniture responses are skipped at unrelated overflow seats or when safe decorative space is unavailable.

The 28-entry provider catalog has configuration and event regression coverage; that does not establish end-to-end verification of every native AI client. Local observation is passive, tool approvals stay in the original tool, and animations never prove a command or full task succeeded. Supported manual question answers remain an explicit, request-scoped user action; see the [monitoring guide](../../office/docs/monitoring.md).
