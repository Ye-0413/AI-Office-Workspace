# AI Work Space 的 5A 验收标准

这是一套项目自定的标准，适用于观察真实 AI 会话并把它们画成角色的桌面应用。每一项分别记为「通过」「需改进」或「待验证」。五项均有当次版本的通过证据，才可将该版本评为 5A。

| 维度 | A 级验收条件 | 复查方法 |
| --- | --- | --- |
| 应用质量 | 新配置可以启动，窗口崩溃后能恢复。连接诊断有明确结果，安装包可运行。 | 用独立配置启动，运行恢复窗口和打包观察流程测试。 |
| 模型质量 | 一条真实身份对应一个会话。分身、嵌套分身、先到的子会话均沿已知父链归组。兄弟分身共享家族标识，独立任务各有标识。 | 回放乱序和重复事件，交换快照顺序，比较角色身份、家族编号和外观。 |
| 交互质量 | 即使同一主角色同时拥有许多分身，也可以找到每一位、打开详情，关闭后焦点回到伙伴名单入口。搜索、键盘操作和「只看需留意」筛选都可独立使用。 | 构造拥有多个分身的两组任务，测试收起、展开、搜索、选择和返回焦点。 |
| 代码质量 | 房间、名牌和名单复用同一条归组规则。关键行为有回归用例，完整单元测试通过。 | 检查各显示入口，运行应用自己的测试命令，并记录失败及复现条件。 |
| 用户体验 | 用户凭形象与文字编号就能认出一组角色。中英文、减少动态效果和拥挤场景均能读出同一归属，名单能解释画面里收起的成员。 | 在两种语言和两种美术风格检查同一组角色，同时核对可见数量、文字标识和辅助名称。 |

## 复评记录

2026 年 11 月 18 日，以主分支 `30e60b8`（v0.25.0）为基线，检查包含本轮改动的工作区。运行环境为 Apple 芯片 Mac、macOS 27.2、Electron 41.10.4。下列场景使用独立配置和合成会话，便于复现。

五项均通过本次桌面自动化验收。39 个已注册的 Electron 回归场景全部通过，包含实际渲染进程崩溃后自动重载并恢复原会话，以及两个家族并存时的折叠与识别。

| 维度 | 本轮发现和复验结果 |
| --- | --- |
| 应用质量 | 活进程持有配置锁超过一小时后，其他进程原先可能回收这把锁。修复后，模拟持锁两小时仍能保留原文件，已退出的进程及超时的无 PID 锁继续可回收。arm64 应用包通过完整性、28 种接入配置、测试事件传递和 SQLite 重开检查。 |
| 模型质量 | 先到的兄弟分身原先可能各自分到家族编号。现在先用已上报的父任务 ID 归组，后续沿已知父链识别主角色。回放父角色迟到、嵌套、乱序和中间角色缺席的快照，同组的造型、配色和编号保持一致；两个独立主角色保有各自标识。 |
| 交互质量 | 在能容纳全组的房间送入 1 个主角色和 5 个活跃分身。默认可见 3 个分身，主角色名牌计入另外 2 个，名单可检索全部 6 项。展开后 5 个分身均出场，收起后仍能打开折叠成员的任务详情。关闭详情后，键盘焦点回到名单入口。 |
| 代码质量 | 角色造型、名牌和伙伴名单采用同一份会话家族信息。新增测试覆盖缺失父链、每组独立折叠和真实 Electron 窗口里的操作。全量单元测试 1,853 项通过、0 项失败，另有 1 项需要本机授权的上游参考美术素材而跳过。 |
| 用户体验 | 在减少动态效果开启时，从英文像素风切换到中文手绘风，分身保留了同组造型和文字编号。两个家族同时出现时，11 个名单条目仍可分别归组。Chromium 无障碍树中可以读到展开开关的名称，以及折叠成员按钮的家族编号和折叠状态。 |

### 如何复查

在 `office` 目录运行 `npm test` 和 `npm run verify:renderer`。其中 `test/grouped-helpers-renderer.cjs` 检查折叠、展开、双语和两组角色，`test/appearance-renderer.cjs` 检查父子外观及父任务迟到，`test/interaction-renderer.cjs` 检查搜索、筛选和键盘焦点。打包后运行 `npm run verify:bundle`、`npm run verify:packaged-flow` 和 `npm run verify:packaged-usage`。

复评范围为本地 macOS 桌面应用。28 种工具的接入检查使用隔离配置；每个工具的真实客户端版本兼容性、首次用户识别分组所需的时间和实际屏幕阅读器体验，均须单独验证。
